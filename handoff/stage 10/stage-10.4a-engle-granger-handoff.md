## 1. Why 10.4 is two items

`development-sequence.md`'s row 10.4 reads *"Cointegration —
Engle-Granger"* and lists `tseries::po.test` (R) and
`statsmodels…coint` (Python) as its two references, as though they were
two views of one test. `[V]` On the same cointegrated fixture:

```
tseries::po.test(Y, demean=TRUE)     statistic = -128.400260380   p = 0.0100 (capped)
statsmodels coint(method='aeg')      statistic =   -5.746952529   p = 5.59e-06
```

Phillips-Ouliaris is a **Z-type** (normalized bias) statistic;
augmented Engle-Granger is a **tau-type** (t-ratio). Different null
distributions, different tables, different scales, different
small-sample behaviour. The row cannot be implemented or verified as
written.

This document is **10.4a, the tau test**.
`stage-10.4b-phillips-ouliaris-handoff.md` is the Z test.

- **Depends on:** 10.0 (`_mols` is not needed — this is a
  single-response regression — but `tsmatrix` is), `_ols`
  (`src/unitroot.jl:51`), `adf_test`'s regression machinery
  (`src/unitroot.jl:401`), `_horner` (`:129`), and **new MacKinnon
  tables for N > 1** (§4).
- **Does not depend on 10.1.** No VAR is fitted. This item can be built
  in parallel with everything else in the stage.

## 2. Scope

### In

- `coint_test(Y; trend, lags, autolag)` — the two-step test:
  regress the first column on the rest (plus deterministic terms), then
  run a no-constant ADF on the residual.
- MacKinnon response-surface p-values and critical values for
  `N = 2 … 6` (p-values) and `N = 2 … 12` (critical values).
- Honest refusal beyond that coverage, and for the `:none` trend case
  where the tables are N = 1 only.

### Out

- Johansen (10.5) and VECM (10.6).
- Phillips-Ouliaris (10.4b).
- The Engle-Granger **two-step estimator** of the cointegrating vector
  as a reported model object. This item is a *test*; the long-run
  coefficients come back as a by-product and should be returned, but
  inference on them belongs with 10.6.
- Gregory-Hansen (cointegration with a structural break). No installed
  reference; note as unimplemented.

## 4. The tables, and the coverage limits that bound the answer

`src/unitroot.jl:123–126` says, verbatim:

> Only N=1 (a single time series -- the only case `adf_test`/`pp_test`
> ever need) is transcribed; statsmodels'/arch's own N=2:12
> (multi-series cointegration) tables are not, so this project doesn't
> carry untested numbers nobody calls.

That deferral now comes due. Both references carry the tables and
**agree**, which makes the transcription verifiable.

### 4.1 Coverage, established by making each reference fail

`[V]` statsmodels raises `IndexError` at its boundaries, so the limits
are exact rather than inferred:

| Quantity | `regression = "c"`, `"ct"`, `"ctt"` | `regression = "n"` |
|---|---|---|
| p-value (`mackinnonp`) | **N = 1 … 6**; N=7 → `IndexError: list index out of range` | **N = 1 only** |
| critical values (`mackinnoncrit`) | **N = 1 … 12**; N=13 → `IndexError: list index out of range` | **N = 1 only**; N=2 → `IndexError: index 1 is out of bounds for axis 0 with size 1` |

`[V]` `urca:::.urcval(arg, nobs, niv, itt, itv, nc)` covers **N = 1 … 12
for all four trend cases**, both critical values and p-values — wider
than statsmodels, and the independent check.

and `atol=2e-2` on p-values, and record the urca value in a comment**;
tightening either would be asserting one vintage over the other.

`[S]` The existing N=1 transcription in `src/unitroot.jl:131–176` is the

### 4.4 The honest refusals this coverage forces

`[V]` **statsmodels returns `NaN` critical values rather than erroring**
when asked for the no-constant case at N > 1:

```
coint(y, X, trend="n")  ->  stat = -2.641054523, p = 6.675122e-02,
                            crit = [nan, nan, nan]
```

It has an N=2 p-value surface for `nc` but only an N=1 critical-value
table, so it answers half the question and fills the rest with `NaN`.
That is exactly the failure mode this project refuses.

**Decisions:**

- `N > 6` with `c`/`ct`/`ctt`: return critical values, **refuse the
  p-value** by name, pointing at the critical values.
- `N > 12`: refuse both.
- `trend = :none` with `N > 1`: refuse both, and say in the message that
  MacKinnon's no-constant surfaces are tabulated for a single series
  only. Do not return a p-value with `NaN` critical values beside it.
- Never return `NaN` in either field.

## 5. The statistic is only reproducible with the lag pinned

`[V]` This is the single most important implementation finding.

An independent Engle-Granger built by hand in R — OLS on the
cointegrating regression, then `urca::ur.df(type="none")` on the
residual — reproduces statsmodels' `coint` **exactly when the lag is
fixed**, and diverges when each side selects its own:

| Fixture | trend | R (AIC-selected) | statsmodels (`autolag="aic"`) | diff |
|---|---|---|---|---|
| `coint2_yes` | c | −5.746952529 | −5.746952529 | **1.8e-15** |
| `coint2_no` | c | −1.927453742 | −1.451415206 | 4.8e-01 |
| `coint3_r1` | c | −9.572117345 | −12.266871635 | 2.7e+00 |
| `coint2_trend` | ct | −7.736658504 | −16.642272736 | 8.9e+00 |

At **fixed lag 4**, every case agrees:

| Fixture | trend | R, `selectlag="Fixed"`, lags=4 | statsmodels, `maxlag=4, autolag=None` |
|---|---|---|---|
| `coint2_yes` | c | −5.278983513620 | −5.278983514 |
| `coint2_no` | c | −1.258083608751 | −1.258083609 |
| `coint3_r1` | c | −6.753428704193 | — |
| `coint2_trend` | ct | −5.857085337938 | — |
| `coint2_yes` | n | −2.641054523033 | −2.641054523 |

So the test itself is unambiguous and the **lag-selection rule is the
only thing the two references disagree about** — `ur.df(selectlag="AIC")`
searches down from `lags`, statsmodels' `autolag="aic"` searches its own
grid, and they land in different places on three of four fixtures.

**Decisions:**

1. The primary tests assert the **fixed-lag** values, which are exact.
2. `lags` is a required-feeling keyword with an explicit default
   (`floor(12 * (T/100)^0.25)`, Schwert's rule, which is what
   `adf_test` already uses — `[S]` check `src/unitroot.jl:401`'s
   `maxlag` default and reuse it rather than inventing a second rule).
3. `autolag=:aic | :bic | :tstat | nothing`, delegating to
   `adf_test`'s own already-verified selection, so TSAnalytics has
   **one** lag-selection implementation rather than a second one that
   has to be argued about.
4. The docstring states plainly that an autolag-selected statistic will
   not match `urca` or `statsmodels` in general, and that passing an
   explicit `lags` reproduces both.

## 7. A defect in statsmodels' `coint`

`[V]` **`coint(y, X)` with an empty `X` returns a result.** It silently
becomes a plain ADF of `y` and reports N=1 critical values:

```
coint(Y[:,0], Y[:, 0:0], trend="c")
  -> CointResult(coint_t=-1.9031209664892392,
                 pvalue=0.33059433701277763,
                 critical_values=[-3.45688813, -2.87321851, -2.57299362])
```

A cointegration test on one series is not a cointegration test. `[V]`
`tseries::po.test` refuses the analogous input cleanly: *"x is not a
matrix or multivariate time series"*.

**TSAnalytics refuses:** fewer than two series is an `ArgumentError`
naming `adf_test` as what the caller probably wants. Add this to the
charter §5.10 list.

## 8. Proposed Julia API

```julia
struct CointTest <: HypothesisTest
    statistic::Float64
    pvalue::Float64                      # NaN is NOT used; see critical_values
    critical_values::NamedTuple          # (; levels, values)
    N::Int                               # number of series
    trend::Symbol
    lags::Int
    autolag::Union{Nothing,Symbol}
    nobs::Int
    beta::Vector{Float64}                # the cointegrating regression's coefficients
    resid::Vector{Float64}               # the residual the ADF ran on
    pvalue_available::Bool
end

coint_test(Y;
           trend::Symbol = :const,        # :none | :const | :trend | :quadratic
           lags::Union{Nothing,Integer} = nothing,
           autolag::Union{Nothing,Symbol} = :aic) -> CointTest
```

`trend` uses the charter §5.2 vocabulary, mapped to statsmodels'
`n`/`c`/`ct`/`ctt` in the docstring. The first column of `Y` is the
dependent variable — state that loudly, because the statistic is **not**
symmetric in the ordering, and add a test for it (§9.5).

When the p-value is unavailable (§4.4), `pvalue_available = false` and
`pvalue(t)` throws an `ArgumentError` naming `critical_values` —
following the charter §6.4 contract extension that 10.5 also needs. Do
not store `NaN`.

### 9.5 Asymmetry, and the regression by-products

```julia
@testset "the test is not symmetric in column order" begin
    Y = read_fixture("coint2_yes.csv")
    a = coint_test(Y;              trend=:const, lags=4, autolag=nothing)
    b = coint_test(Y[:, [2, 1]];   trend=:const, lags=4, autolag=nothing)
    @test !isapprox(a.statistic, b.statistic; atol=1e-3)
    # the docstring must say the FIRST column is the dependent variable
    @test length(a.beta) == 2          # [const, x] for trend=:const, N=2
end

@testset "cointegrating regression by-products" begin
    Y = read_fixture("coint2_yes.csv")      # z = 2 + 1.5x + stationary
    t = coint_test(Y[:, [2, 1]]; trend=:const, lags=4, autolag=nothing)
    # regressing z on x: slope near 1.5, intercept near 2
    @test t.beta[1] ≈ 2.0 atol=0.6
    @test t.beta[2] ≈ 1.5 atol=0.1
    @test length(t.resid) == 250
    # the residual is what the ADF ran on
    @test abs(mean(t.resid)) < 1e-8        # OLS with an intercept
end
```

### 9.6 Lag handling, and the autolag caveat

```julia
@testset "lags and autolag" begin
    Y = read_fixture("coint2_yes.csv")
    @test coint_test(Y; trend=:const, lags=4, autolag=nothing).lags == 4
    # the default follows adf_test's own Schwert rule, not a second rule
    d = coint_test(Y; trend=:const, autolag=nothing)
    @test d.lags == floor(Int, 12 * (250/100)^0.25)
    # autolag delegates to adf_test's already-verified selection
    for al in (:aic, :bic, :tstat)
        t = coint_test(Y; trend=:const, autolag=al)
        @test 0 <= t.lags <= d.lags
        @test t.autolag === al
    end
    @test_throws ArgumentError coint_test(Y; trend=:const, autolag=:bogus)
    @test_throws ArgumentError coint_test(Y; trend=:const, lags=-1)
    @test_throws ArgumentError coint_test(Y; trend=:const, lags=200)
end
```
