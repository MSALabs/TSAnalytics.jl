API: Regime Switching

Models whose parameters change with an unobserved regime that follows a Markov chain (Hamilton 1989). The transition matrix is left-stochastic: P[i, j] = Pr(S_t = i | S_{t−1} = j), so its columns sum to one.

Fitting

TSAnalytics.fit_ms_regression — Function
fit_ms_regression(y; k=2, exog=nothing, trend=true, switching_trend=true,
                  switching_exog=false, switching_variance=false,
                  exog_tvtp=nothing, initial=nothing, em_iter=5,
                  n_starts=10, rng=Random.default_rng(), params=nothing) -> MSModel

Markov-switching regression (Hamilton 1989):

y_t = c_{S_t} + x_t' β_{S_t} + ε_t,   ε_t ~ N(0, σ²_{S_t})

with S_t a first-order Markov chain with left-stochastic transition matrix P (P[i,j] = Pr(S_t = i | S_{t−1} = j)). Putting lagged y in exog gives R's MSwM model, which is not Hamilton's switching autoregression – that is fit_ms_autoregression.

  • k: the number of regimes (k = 1 is allowed and is an exact reduction to least squares).
  • switching_trend, switching_exog, switching_variance (and, for the autoregression, switching_ar): which parameters vary by regime. A specification in which nothing switches is refused – its transition probabilities are not identified, and statsmodels silently returns its starting values for them.
  • exog_tvtp: covariates for time-varying transition probabilities (include a column of ones for a constant); the transition parameters are then logits.
  • initial: the regime distribution at t = −order (before the first usable observation); default the steady state of P, as statsmodels. R's MSwM estimates it instead, which moves the likelihood (by 0.072 on the canonical fixture).
  • em_iter EM steps (default 5) warm-start each of n_starts (default 10) gradient fits, run on threads; the best is returned and n_modes reports how many distinct optima were found. The likelihood is multimodal: on Hamilton's GNP series only about two thirds of random starts reach the global maximum, pure EM stops on a no-persistence ridge, and with a switching variance the reference's own default fit is a local optimum 1.36 below the best.
  • params evaluates the model at given parameters (in coefnames order) without fitting.

switching_exog defaults to false here and in the autoregression; the reference defaults it to true in one class and false in the other.

TSAnalytics.fit_ms_autoregression — Function
fit_ms_autoregression(y, order; k=2, exog=nothing, trend=true,
                      switching_trend=true, switching_exog=false,
                      switching_ar=false, switching_variance=false,
                      exog_tvtp=nothing, initial=nothing, em_iter=5,
                      n_starts=10, rng=Random.default_rng(), params=nothing) -> MSModel

Hamilton's (1989) Markov-switching autoregression, in its mean-adjusted form:

y_t − μ_{S_t} = Σ_{j=1}^{order} φ_j (y_{t−j} − μ_{S_{t−j}}) + ε_t

The regime at every lag enters, so the filter runs over the k^(order+1) joint regime states. fit_ms_autoregression(y, 4) with the defaults – switching mean, common AR coefficients and variance – is Hamilton's model for US GNP growth, and reproduces statsmodels' MarkovAutoregression(…, switching_ar=False) (whose own default, switching_ar=True, is a different, 13-parameter model).

  • k: the number of regimes (k = 1 is allowed and is an exact reduction to least squares).
  • switching_trend, switching_exog, switching_variance (and, for the autoregression, switching_ar): which parameters vary by regime. A specification in which nothing switches is refused – its transition probabilities are not identified, and statsmodels silently returns its starting values for them.
  • exog_tvtp: covariates for time-varying transition probabilities (include a column of ones for a constant); the transition parameters are then logits.
  • initial: the regime distribution at t = −order (before the first usable observation); default the steady state of P, as statsmodels. R's MSwM estimates it instead, which moves the likelihood (by 0.072 on the canonical fixture).
  • em_iter EM steps (default 5) warm-start each of n_starts (default 10) gradient fits, run on threads; the best is returned and n_modes reports how many distinct optima were found. The likelihood is multimodal: on Hamilton's GNP series only about two thirds of random starts reach the global maximum, pure EM stops on a no-persistence ridge, and with a switching variance the reference's own default fit is a local optimum 1.36 below the best.
  • params evaluates the model at given parameters (in coefnames order) without fitting.

R's MSwM cannot express this model: it puts the lags in as plain levels. On the canonical fixture its specification evaluated at statsmodels' parameters is 13.2 log-likelihood units away – a different model, not a different optimum.

julia> using TSAnalytics, DelimitedFiles

julia> gnp = readdlm(joinpath(pkgdir(TSAnalytics), "handoff", "stage 11", "fixtures",
                              "hamilton_rgnp.csv"), ','; skipstart=1)[:, 2];

julia> m = canonicalise(fit_ms_autoregression(gnp, 4));

julia> round(m.loglik, digits=4)
-181.2634

julia> round.(expected_durations(m), digits=2)
2-element Vector{Float64}:
  4.08
 10.43

TSAnalytics.MSModel — Type
MSModel

A fitted Markov-switching model, from fit_ms_regression or fit_ms_autoregression. P is the left-stochastic transition matrix – P[i, j] = Pr(S_t = i | S_{t−1} = j), columns sum to one, the opposite of many textbooks – or nothing when the transition probabilities vary with covariates. Regime probabilities are in regime_probabilities; n_modes counts the distinct optima the restart search found, and mode_logliks lists them.

source

Regimes

TSAnalytics.regime_probabilities — Function
regime_probabilities(m::MSModel; kind=:smoothed) -> Matrix   # nobs × k

Pr(S_t = r | …) for each usable observation (the first order are lags): kind = :smoothed conditions on the whole sample, :filtered on data to t.

source
TSAnalytics.expected_durations — Function
expected_durations(m::MSModel) -> Vector

1 / (1 − P[r, r]): the expected number of periods a regime lasts once entered. (Not defined for time-varying transition probabilities.)

source
TSAnalytics.canonicalise — Function
canonicalise(m::MSModel) -> MSModel

The same fit with its regimes relabelled in a fixed order – ascending intercept, or ascending variance when only the variance switches – so two fits can be compared. The label ambiguity is real: a random start can return exactly the relabelled optimum (parameters 1.5 apart, likelihood equal). For k = 2 relabelling is not (p[0->0], p[1->0]) → (p[1->0], p[0->0]) but → (1 − p[1->0], 1 − p[0->0]), with the regime-specific parameters swapped.
