--- PP :rho, via arch.unitroot.PhillipsPerron (arch 5.1.0), real execution ---

IMPORTANT FINDING: arch's own adf_z_* tables
(arch.unitroot.critical_values.dickey_fuller) are NOT the same numbers
as adfvalues_source.py's z_star_c/z_c_smallp/z_c_largep tables (e.g.
arch's z_star['c']=-5.04709 vs adfvalues_source.py's z_star_c[0]=-8.9)
-- confirmed these are for a different Z-test. arch's PhillipsPerron
class computes stat_rho via the *exact same formula* this project's
pp_test already implements, and gets its p-value from arch's adf_z_*
tables via dist_type="ADF-z" -- that end-to-end match is what confirms
arch's tables (not adfvalues_source.py's) are the correct ones for this
project's pp_rho_pvalue. Implemented using arch's tables accordingly.
